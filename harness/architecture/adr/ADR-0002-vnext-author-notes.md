# ADR-0002：VNext 作者笔记的最小应用状态

日期：2026-10-15。状态：已实施的工程选择。

## 范围

本轮只把作者非正式笔记纳入共享契约：content、可选 chapterId、purpose（普通笔记 / 下次要写）、status（进行中 / 归档）、服务端 ID、版本、作者与时间。不新增「已确认事实」状态，不写 Markdown Harness。

## 约束

- 单机文件状态按项目编码存储。笔记、重试结果与审计在同一锁和原子 rename 事务内提交。
- 创建与修改都必须带 Idempotency-Key。修改还必须带 baseVersion。过期修改返回 NOTE_VERSION_CONFLICT。
- 一个项目仅一条 active next_writing。已有计划时返回 NEXT_WRITING_EXISTS，作者需明确编辑或归档旧计划。
- 笔记读取、创建、修改只允许服务端认证的 author。
- Workspace 返回真实能力声明。没有声明的旧服务端禁用笔记入口。
- 保存失败保留当前输入。归档可恢复，没有永久删除端点。

## 暂缓

正式知识关系词汇、正式知识应用事务、结构化注记与审查任务、持久化思考会话、研究引文校验、生产身份。它们分别需要产品决定或 Agent Runtime。

## 限制

文件状态和审计随笔记量增长，未加入分页、跨主机协调或数据库。部署前必须选择身份与存储方案。
