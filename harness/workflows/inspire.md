# 理解与表达研究

目标：帮助作者找到自己的表达方式，不代笔。

1. 用作者原话概括主题。给出「我的理解」和最多两种其他解释，让作者校正。未经确认不写入正式 intent。
2. 将表达目标拆成情绪、冲突、人物选择、读者应自行领悟的部分。
3. 找 2–3 个可核验案例：作品、作者、章节或场景、版本或译本、URL 或出版信息、访问日期。
4. 区分「作品实际内容」与「你的分析」。引文必须逐字核验，不能拿记忆冒充原文。找不到来源就标未核验。
5. 比较机制：视角、行动、对白、留白、信息延迟、意象、情绪结果。指出可借鉴与不适合本书之处。
6. 给作者 3 个启发问题与至多 3 个结构实验，说明代价，不生成可当作正文的场景。

输出 references/ 案例卡及 notes/ 灵感记录。只有作者采纳后才转为提案。无检索能力时要求作者提供片段或链接，不假称已查阅。
