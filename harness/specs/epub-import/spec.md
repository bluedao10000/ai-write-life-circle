# EPUB 导入

## 行为

导入器接受 EPUB 2/3 文本型文件，读取 OPF 元数据、spine 阅读顺序和 EPUB 3 NAV 或 EPUB 2 NCX 目录，生成可编辑的作品导入预览。解析过程只还原正文和基本结构，不调用模型，也不提交正式作品。

### 章节识别

- OPF spine 是正文的权威阅读顺序。非线性内容不并入正文，并在预览中显示警告。
- 可用目录用于识别卷、章节和锚点范围。单个 XHTML 可以包含多个章节，一个章节也可以跨越多个 spine 文件。章节内嵌套小节保留在父章正文中。
- EPUB 明确标记为封面的页面不构成正文章节。完全空白的目录目标也不会保留为空章；目录项均未指向包含可导入正文的 spine 文档时，按 spine 文件顺序回退并显示目录不可用警告。未标记且仅含标题的页面保留标题，并附到后续首个正文 spine 片段，不单独生成书名章。
- 不根据 `titlepage.xhtml`、`cover.xhtml` 等文件名跳过内容；有效目录指向的 heading-only 章节起点仍与后续 spine 正文保持同一章节。
- 目录只覆盖部分正文时，保留可识别目录范围和未覆盖正文，并显示目录不完整警告。
- 没有目录时按 spine 文件切分并显示目录缺失警告。
- 正文段落、标题、强调、引用、列表和插图说明转换为 Markdown；文本顺序与 spine 一致。
- 每章 Markdown 不超过 2 MiB。超过上限时预览失败并返回 `EPUB_CHAPTER_TOO_LARGE`，不降低或扩大该限制。

### 文件与内容限制

| 项目 | 上限或策略 |
| --- | --- |
| EPUB 文件 | 64 MiB |
| 解压总量 | 256 MiB |
| ZIP 条目 | 10,000 |
| 单个 ZIP 条目 | 32 MiB |
| 章节数 | 2,000 |
| 单章 Markdown | 2 MiB |

支持 UTF-8 和声明为 GBK 的正文。加密或 DRM、固定版式、危险或重复路径、异常 ZIP 文件类型和超限内容会拒绝。章节或内容无效时返回明确的解析错误，不生成预览。

### 预览与提交

- 作者可以编辑书名、卷名和章名，再显式确认导入。
- 预览期间作品不可见；确认后按章节创建初始 Revision，并在全部写入完成、校验通过后一次性公开作品目录。
- 重试使用现有幂等回执，不能重复创建作品或初始 Revision。
- 知识抽取仍需作者在书页显式授权。

## Acceptance scenarios

Scenario: 目录只指向无正文封面页时按 spine 拆分正文并保留标题

验收：A1

Given 一个 EPUB 的 NCX/NAV 只包含指向无可导入正文封面页的目录项
And 后续 spine 文件包含正文
When 解析并生成预览
Then 正文按 spine 阅读顺序保留且不重复
And 明确标记的封面和完全空白的目录目标不生成章节
And 未标记的标题单独页保留在首个正文片段中，不单独生成书名章
And 预览显示目录不可用警告

Scenario: spine 回退后分别执行单章容量限制

验收：A2

Given 一个空封面目录项后有两个正文 spine 文件
And 每个正文文件转换后的 Markdown 小于 2 MiB，但合计大于 2 MiB
When 解析并生成预览
Then 两个正文文件成为独立章节且完整保留
And 若一个正文章节单独超过 2 MiB，则返回 `EPUB_CHAPTER_TOO_LARGE`

Scenario: 正文目录继续提供章节和跨文件边界

验收：A3

Given 一个可用目录指向正文章节，章节可以跨越多个 spine 文件或包含嵌套小节
When 解析并生成预览
Then 章节边界、卷结构、正文顺序与嵌套小节遵循目录
And EPUB 解析现有回归保持通过

Scenario: 单章标题单独位于首个 spine 文件时与后续正文合并

验收：A3

Given 一个有效目录只指向标题单独位于首个 spine 文件的单章起点
And 该章节正文位于后续 spine 文件
When 解析并生成预览
Then 章节标题与后续正文保留在同一章节中
And 不因页面文件名是 `titlepage.xhtml` 或 `cover.xhtml` 而删除标题或正文
