# apps/context —— 小说上下文工作区

这里是你写小说的「后台」。你负责写，AI 负责记和问。

## 谁做什么

| | 你（作者） | AI |
| --- | --- | --- |
| 写小说正文 | ✅ `manuscript/` | ❌ 只读，绝不代写 |
| 写创作笔记 | ✅ `notes/` | ❌ 只读提炼 |
| 维护上下文 | 对话里确认 | ✅ `context/`（人物 / 世界观 / 时间线 / 剧情结构 / 伏笔） |
| 找缺口、联网查资料 | —— | ✅ |

一句话：**小说正文的每个字都是你写的；AI 只在你背后把「看不见的那层设定」记清楚、问明白。**

## 目录速览

| 目录 | 谁维护 | 放什么 |
| --- | --- | --- |
| `manuscript/` | 你 | 小说正文 |
| `notes/` | 你 | 创作笔记、灵感、随手记 |
| `context/` | AI | 小说上下文（五维） |
| `references/` | AI | 联网查来的参考资料 |
| `state/current.md` | AI | 当前进度、健康度快照、待办 |
| `harness/` | 规范 | 工作流与契约文档 |

## 怎么开始

1. 把你想写的故事，随便聊几句：主角是谁、想讲什么。
2. AI 会把它整理进 `context/`，并告诉你上下文哪里扎实、哪里空着。
3. 你只管写正文、写笔记；AI 在你写完后同步、核对、提醒。

## 三条约定

1. **AI 不代写正文**，也不改你的笔记。
2. **对话里说定的事，AI 直接记**，不用你填表。
3. **每次聊完或写完，AI 会给你一份健康度看板**：哪做得好、哪还缺、下一步问什么。

想了解 AI 具体怎么做，看 [harness/index.md](harness/index.md)。
