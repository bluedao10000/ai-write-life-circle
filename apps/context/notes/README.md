# 创作笔记（notes/）

**你的地盘。** 这里放创作笔记、灵感、随手记。AI 只读提炼，不篡改。

## 写什么

- 灵感碎片、人物小传草稿、设定草稿
- 「下一章想写什么」的备忘
- 对某段情节的犹豫、备选方案

## 约定

- 文件名随意，`日期-主题.md` 或按需。
- 笔记是你思考的痕迹，不用整理成正式文档。
- AI 会从中提炼设定进 `context/`，但**笔记原样保留**，一个字不动。

## 与 context 的区别

- `notes/`：你随手写的、原始的想法。
- `context/`：AI 整理过的、结构化的设定（带状态、来源、显隐）。

想法先在 notes 里发芽，成熟了由 AI 收进 context。
