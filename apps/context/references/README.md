# 参考资料（references/）

AI 联网查来的资料沉淀在这里，ID 前缀 `REF-`。作者可以随时核对。

## 条目模板

```markdown
---
id: REF-<序号>
title: <资料主题>
topic: <对应哪个维度的缺口，如 worldview / character / plot>
source: <出处 URL 或书名>
retrievedAt: <日期>
---

## 要点

## 可落地的方向（2-3 个）

1. <方向一：依据 + 适用场景 + 代价>
2. <方向二>
3. <方向三>

## 备注
```

## 约定

- 只放「有据可查」的资料，标出处。
- 外部资料只作参考，不直接进正文，不伪造来源。
- 作者选定方向后，结论进 `context/`，这里留原始依据。
