# 健康度看板规范

每次对话或正文 / 笔记同步结束，AI 必须在回复末尾输出一份看板。格式固定，篇幅克制。

## 看板模板

```
📊 小说上下文健康度

【五维速览】
人物 ████░░ 人物立起来了，关系网待补
世界观 ██░░░░ 只有一条规则，缺地点与势力
时间线 ░░░░░░ 空
剧情结构 ███░░░ 有三幕骨架，冲突偏少
伏笔 █░░░░░ 埋了 2 个，都没回收

✨ 做得好
- 主角的 want / need / fear 齐了

🧩 待补充
- [major] 时间线为空，无法校验前后一致性
- [major] 伏笔只埋不收

💡 下一步
- 先把时间线补起来：按顺序说说已经发生的关键事件？
- 世界观要不要我联网查点同类设定的资料？
```

## 四段要求

| 段 | 内容 |
| --- | --- |
| 五维速览 | 每维一条进度条 + 一句话判断 |
| ✨ 做得好 | 肯定已成体系的设定，1-3 条 |
| 🧩 待补充 | 标严重度（critical / major / minor）的缺口，按序 |
| 💡 下一步 | 1-2 个具体问题，或「要我联网查 X 吗」 |

## 严重度口径

| 级别 | 含义 | 例子 |
| --- | --- | --- |
| critical | 核心缺失，故事立不住 | 没有主角 |
| major | 影响一致性 / 驱动力 | 时间线空、伏笔断线、缺冲突 |
| minor | 可选完善 | 关系稀疏、主题不明 |

## 五维评估标准

### 人物
- 充实：有主角，want / need / fear 齐，有弧光，关系网连得上。
- 缺失：没主角、动机空白、无弧光、关系稀疏。

### 世界观
- 充实：至少一条硬规则 + 地点 + 势力 + 主题。
- 缺失：零规则、全是软规则、无地点。

### 时间线
- 充实：事件有序、无矛盾、可校验前后一致。
- 缺失：空、顺序不清、有 contradicted。

### 剧情结构
- 充实：有结构骨架、情节点齐、有冲突、定位到当前进度。
- 缺失：无骨架、无冲突、不知道写到哪。

### 伏笔
- 充实：有埋有收，回收率健康，无断线。
- 缺失：只埋不收、有 dangling。

## 频率

不主动刷屏。这些节点必出看板：

1. 每写完一卷 / 若干章。
2. 作者主动问「上下文怎么样了」。
3. 出现 critical 或大量 major 缺口。

平时只在「会影响后续一致性」或「作者询问」时开口，不打断创作。
