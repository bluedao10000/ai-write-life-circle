# 正文 / 笔记同步

作者在 `manuscript/` 或 `notes/` 新增、修改内容后，AI 从中逆向提炼「以小见大」的细节，核对后同步进 `context/`。

## 触发

- 作者写完 / 改完一章正文。
- 作者新写了笔记。
- 作者明确说「帮我同步一下」。

## 红线

- **AI 只读 `manuscript/` 和 `notes/`**，绝不代写、绝不修改。
- 提炼出的设定，**先核对、后落盘**，不擅自定案。

## 步骤

### 1. 读新增 / 改动的内容

读 `manuscript/` 新章节和 `notes/` 新笔记，对照 `context/index.md` 现有条目。

### 2. 逆向提炼「以小见大」的细节

不是摘抄正文，是挖出正文没明说的设定：

| 正文现象 | 可提炼的上下文 |
| --- | --- |
| 一句台词里的态度变化 | 人物关系 / 动机 |
| 反复出现的一个物件 | 世界观规则 / 伏笔 |
| 一个看似闲笔的场景 | 时间线事件 / 地点 |
| 人物一个反常的小动作 | 隐性创伤 / 伏笔 |

### 3. 核对

把提炼出的候选条目，在对话里向作者确认：

- 作者认 → `confirmed`。
- 作者说不清楚 → `speculative`，挂来源。
- 与现有条目冲突 → 标 `contradicted`，请作者仲裁。

### 4. 落盘

按 [data-contract](../data-contract.md) 写入 `context/` 对应目录，`sources` 挂 `manuscript` 或 `note` + 章节 / 位置。

## 完成后

更新 `context/index.md` 与 `state/current.md`，出健康度看板。若提炼出关键缺口，看板里点出来。

## 反例

- ❌ 直接改写正文里含糊的地方，替作者「补全」。
- ✅ 只记进 context，正文一个字不动。
