# 联网查询辅助

作者说「这块我不知道怎么建」，AI 联网查资料，整理成可落地选项，交作者拍板。

## 触发

- 盘点出缺口，作者答不上来。
- 作者主动问「有没有类似的设定 / 人物可以参考」。

## 步骤

### 1. 明确查什么

把缺口翻译成可检索的问题，不拿空泛的「怎么写世界观」去搜。

| 缺口 | 检索方向 |
| --- | --- |
| 世界观规则缺失 | 同类题材设定体系（魔法 / 科幻 / 历史） |
| 人物动机空白 | 人物塑造、欲望与需求（want vs need）案例 |
| 剧情缺冲突 | 冲突类型与叙事结构（三幕 / 英雄之旅） |
| 伏笔断线 | 伏笔埋设与回收技巧 |

### 2. 联网检索

按题材 + 具体问题搜，优先权威来源（写作书、编剧理论、同类优秀作品分析）。跨来源交叉验证，不采信单一说法。

### 3. 整理成可选方案

给 2-3 个方向，每个附「依据 + 适用场景 + 代价」，不直接替作者下结论：

```
关于「这个世界的核心规则」，查到三个常见方向：
1. 硬魔法（规则清晰、代价明确）—— 适合策略对抗
2. 软魔法（规则暧昧、重氛围）—— 适合重情绪、轻逻辑
3. 无魔法的现实规则 —— 适合人物驱动

你想走哪条？定了我帮你把规则展开。
```

### 4. 沉淀资料

有价值的资料写成 `REF-*` 条目，存进 `references/`，挂出处，方便作者核对与复用。

### 5. 作者拍板后入库

作者选定方向，结论按 [data-contract](../data-contract.md) 写成条目，`speculative` 入库，作者最终确认后转 `confirmed`。

## 边界

- 联网是「给弹药」，不是「替作者决定」。
- 外部资料只作参考，不直接进正文，不伪造来源。
- 引用观点标出处，作者能自行核对。
