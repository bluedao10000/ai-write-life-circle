# 全局盘点与缺失诊断

定期把五维上下文过一遍，找出留白与薄弱点，产出健康度看板。

## 触发

- 作者问「上下文现在怎么样了」。
- 每写完一卷 / 若干章。
- 连续多轮对话没做盘点时。

## 步骤

### 1. 读总索引

读 `context/index.md`，拿到五维各有多少条目、什么状态。

### 2. 逐维盘点

按 [health-board](../health-board.md) 的五维评估标准，逐个判断「充实 / 缺失」：

- 人物：主角、动机、弧光、关系。
- 世界观：硬规则、地点、势力、主题。
- 时间线：事件数、顺序、矛盾。
- 剧情结构：骨架、情节点、冲突、进度。
- 伏笔：埋 / 收、断线。

### 3. 标严重度

缺口分 critical / major / minor（口径见 [health-board](../health-board.md)）。

### 4. 出看板

按看板模板输出，结论先行：

```
整体覆盖度约 45%。人物立住了，世界观和时间线是短板。
```

然后「做得好」「待补充」「下一步」。

### 5. 给下一步，不给清单

一次只推一个最要命的缺口，附一个具体可答的问题。作者答不上来 → 转 [web-research-assist](web-research-assist.md)。

## 完成后

把本次快照写进 `state/current.md`（覆盖度、待补项、下一步）。
