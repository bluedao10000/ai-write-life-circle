### 最终结构（纯 Markdown）
- `harness/`：index（路由）、data-contract（条目格式 + frontmatter 元数据 + ID 规范）、health-board（看板规范 + 五维评估标准）、workflows/（dialogue-co-build / sync-manuscript-notes / diagnose-gaps / web-research-assist）
- `context/`：index（总索引）+ characters / world / timeline / structure / foreshadowing 五维子目录（各含条目模板 README）
- `manuscript/`、`notes/`（作者写，AI 只读）、`references/`（AI 联网沉淀 REF-*）、`state/current.md`

### 核心规范（已固化进文档）
- 人机分工：人类写正文/笔记，AI 维护上下文，**AI 严禁代写正文**。
- 来源优先级：对话（主）> 正文 ≈ 笔记（次）。
- 条目状态机：confirmed / speculative / contradicted / stale；显隐：explicit / implicit / unwritten（冰山之上/之下）。
- 每次对话/同步尾声输出「健康度看板」（五维速览 + 做得好 + 待补充 + 下一步）。
- ID 前缀：CHAR-/WORLD-/EVENT-/STRUCT-/FORE-/REF-。
